# NOKTURN

Strona NOKTURN w Next.js + Tailwind. Animacje: motion, @number-flow/react.

## Start
npm install
npm run dev     # http://localhost:3000

## Przed publikacją
Uzupełnij src/lib/site.ts: numer demo, link Calendly, ceny, dane firmy.
Wklej treść polityki prywatności i regulaminu w src/app/polityka-prywatnosci i src/app/regulamin.

## Vercel
Wrzuć repo na GitHub i zaimportuj w Vercel (bez dodatkowych ustawień).
